Game Designer

บทบาทและความรับผิดชอบ (Role and Responsibilities)

  • ช่วยออกแบบและจัดทำเอกสารกลไกเกมเพลย์ (Gameplay Mechanics), ปริศนา, และระบบต่างๆ ของเกม
  • ดูแลและปรับปรุงเอกสาร Game Design Document (GDD) ให้เป็นปัจจุบันอยู่เสมอ
  • ทำงานร่วมกับ Level Designer, 3D Artist และ Programmer เพื่อให้มั่นใจว่าทุกองค์ประกอบของเกม ทั้งเกมเพลย์, ศิลปะ, และเรื่องราว ทำงานร่วมกันได้อย่างกลมกลืน
  • วิเคราะห์และปรับสมดุลของเกมเพื่อสร้างประสบการณ์ที่ท้าทายและน่าจดจำสำหรับผู้เล่น

คุณสมบัติ (Qualifications)

  • มีทักษะในการสื่อสารและการจัดทำเอกสาร Game Design ที่ชัดเจนและเป็นระบบ
  • มีความเข้าใจในจิตวิทยาของผู้เล่นและความสามารถในการออกแบบประสบการณ์ที่เน้นอารมณ์และความรู้สึก
  • มีความคิดเชิงวิเคราะห์และสามารถแก้ไขปัญหาที่ซับซ้อนได้
  • มี Portfolio ที่เกี่ยวข้องกับการออกแบบเกม, การเขียน GDD, หรือโปรเจกต์ที่แสดงให้เห็นถึงแนวคิดการออกแบบ
